Tugas
Tambahkan mode gelap sekaligus untuk editor-kecil dan tombol-tombolnya. Ketentuan warna untuk latar belakang editor-kecil adalah #2e3443, sementara untuk tombol adalah #29ddcc. Teks untuk tombol tetap mengikuti warna teks sebelumnya.

Deskripsi
Program ini menampilkan perubahan warna yang ada dalam web Pengkorversian Gaya Teks.
Tampilan awal yang sudah menghilangkan border pada keempat tombol tersebut.
Lalu saat mengklik tombol "Mode Gelap" akan mengubah warna background dan warna kotak input menjadi gelap. Mengubah warna pada tombol background menjadi biru. Dan mengubah warna teks menjadi putih.
